# DESIGN.md — Bo AI Desktop Visual System

## Visual Identity & World
- **Theme**: "Cyber-Organic Neural Dark"
- **Background Core**: Obsidian Midnight (`#090A0F`, `#0E121B`, `#151B28`)
- **Accents**:
  - Neural Cyan: `#00F0FF` (Listening state, voice waves)
  - Intelligence Violet: `#8B5CF6` / Indigo `#6366F1` (Thinking / Processing state)
  - Living Emerald: `#10B981` (Connected, ready, speaking)
  - Danger Coral: `#F43F5E` (Stop, disconnect, destructive confirmation)
- **Glass & Surface**:
  - Panel Surface: `rgba(20, 26, 40, 0.75)` with `backdrop-filter: blur(16px)`
  - Border: `1px solid rgba(255, 255, 255, 0.08)`
  - Active Glow: `0 0 25px rgba(99, 102, 241, 0.25)`

## Typography
- **Primary Typeface (Thai & Latin)**: Noto Sans Thai (weights 100..900)
- **Mono / Metrics**: JetBrains Mono, Noto Sans Thai, monospace

## Component Signatures
- **AI State Visualizer (Core Orb)**:
  - `idle`: Slow luminous breathing rhythm (Violet)
  - `listening`: Dynamic soundwave reaction & expansion (Cyan)
  - `thinking`: Rotating concentric energy rings (Indigo/Violet)
  - `speaking`: Harmonic audio frequency bars / pulse (Emerald)
- **Frameless Desktop Shell**:
  - Window Drag Bar with title, active state pill, system tray status
  - Native-feeling window controls (Minimize, Maximize, Close)
- **Sidebar Navigation**:
  - Sleek vertical navigation with glowing indicator chips
  - Keyboard shortcuts (Ctrl+1 through Ctrl+7)
